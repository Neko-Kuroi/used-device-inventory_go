在庫管理プログラム（Windows版）
インストールと起動の説明

このプログラムは、中古のスマートフォンやパソコンの在庫を管理するためのものです。 「インストール」という大げさな作業はありません。ファイル1つを置いて、ダブルクリックで起動するだけです。 あとはブラウザ（Edge や Chrome）で開いて使います。

1. 置き場所を作る

  1. パソコンの C ドライブに、新しいフォルダーを作ります。名前は inventory にします（場所は C:\inventory になります）。
  2. 受け取った inventory.exe を、そのフォルダーの中に入れます。
注意: フォルダーは Program Files の中には作らないでください。データの保存で問題が起きることがあります。C ドライブの直下（C:\inventory）が確実です。

データ（在庫の記録や写真）は、このフォルダーの中に自動で作られる instance というフォルダーに保存されます。プログラムとデータは、同じフォルダーにまとまっています。

2. 初めて起動する

  1. inventory.exe をダブルクリックします。
  2. 青い画面で「Windows によって PC が保護されました」と出ることがあります。これは、配布元が不明なプログラムに対する Windows の確認画面です。
    「詳細情報」をクリック → 「実行する」をクリックしてください。この確認は初回だけです。
  3. 黒い画面（ウィンドウ）が開いて、英語の文字が数行表示されます。これで起動できています。
黒い画面について: この画面は「動いています」という表示専用です。文字を入力する画面ではありません（キーボードで打ってもプログラムには届きません）。閉じるとプログラムが止まるので、使い終わるまで開いたままにしておいてください。

3. ブラウザで開いて、管理者を作る（初回だけ）

  1. ブラウザ（Edge や Chrome）を開きます。
  2. 画面の上のほうにあるアドレス欄（インターネットの住所を入れるところ）に、次の文字をそのまま正確に入れます。
http://127.0.0.1:5000/
  1. Enter キーを押すと、「管理者アカウントの作成」という画面が出ます。
  2. ユーザー名とパスワードを決めて入れます。パスワードは8文字以上です。忘れないように、紙などに控えておいてください。
  3. 作成すると、そのままログインした状態で在庫の一覧画面になります。

4. 毎日の使い方

  1. inventory.exe をダブルクリックします（黒い画面が開いたままになります）。
  2. ブラウザで http://127.0.0.1:5000/ を開きます。
  3. ログイン画面が出るので、ユーザー名とパスワードを入れてログインします。
  4. 使い終わったら、黒い画面をクリックして Ctrl キーを押しながら C キーを押すか、黒い画面を閉じます。これでプログラムが止まります。

データは操作のたびに自動で保存されています。「保存」ボタンを探す必要はありません。止め忘れても、パソコンの電源を切れば一緒に止まります。

5. バックアップ（大切なデータの控え）

ときどき、C:\inventory フォルダーごと、USB メモリなど別の場所にコピーしておいてください。それだけで全部の控えになります。戻すときは、コピーしたフォルダーを元の場所に戻すだけです。

6. 他の端末から使う場合（必要なときだけ）

自宅の別のパソコンやスマートフォンから使う場合は、Tailscale という仕組みを使います。この場合は設定する人に相談してください。手順だけ書いておきます。

  1. inventory.exe と同じフォルダーに config.txt というファイルを作ります。
  2. 中身に、次の1行を書きます（アドレス部分は、このパソコンの Tailscale のアドレスに置き換えます）。
addr=100.x.x.x:5000
  1. プログラムを起動し直すと、他の端末のブラウザから http://100.x.x.x:5000/ で開けるようになります。

インターネット上に直接公開する設定ではないので、config.txt に 0.0.0.0 のような書き方はしないでください。

7. 困ったとき

様子確かめること・対処
ブラウザで開けない（「接続できません」など） 黒い画面が開いたままか確認してください。閉じてしまっていたら、inventory.exe をダブルクリックし直します。アドレスが http://127.0.0.1:5000/ と正確に入っているかも確認してください。
黒い画面が一瞬で消えてしまう すでにプログラムが動いている可能性があります。まずブラウザで開けるか試してください。それでもだめなときは、パソコンを再起動してから、もう一度ダブルクリックしてください。
黒い画面に文字が入力できない（日本語だけ入るように見える） 故障ではありません。その画面は表示専用で、入力する場所はブラウザの画面のほうです。
ログインのパスワードを忘れた 次の「8.」の方法で作り直せます。ホストのパソコンを操作できる人だけができる方法です。

8. パスワードを忘れたとき（ホストのパソコンでの操作）

プログラムを止めた状態で、次の手順でパスワードを作り直します。

  1. スタートメニューで「cmd」と検索して、コマンドプロンプトを開きます。
  2. 次の2行を、1行ずつ入れて Enter キーを押します。
cd C:\inventory inventory.exe list-users
  1. ユーザーの一覧が出ます。作り直したいユーザー名を確認します。
  2. 次のように入れて Enter キーを押します（admin の部分は、実際のユーザー名に置き換えます）。
inventory.exe reset-password admin
  1. 新しいパスワードを2回聞かれます。打っても画面には表示されませんが、入力されています。そのまま打って Enter キーを押してください。
  2. 「パスワードを変更しました」と出れば完了です。なお、ログイン中だった人は、新しいパスワードでログインし直す必要があります。
PowerShell を使う場合: PowerShell では、今いるフォルダーのプログラムを実行するとき、頭に .\ を付ける決まりがあります。上のコマンドは .\inventory.exe list-users のように書いてください。「用語が認識されません」というエラーが出たら、この書き方の問題です。
