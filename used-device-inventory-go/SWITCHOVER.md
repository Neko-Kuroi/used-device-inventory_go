# Python 版との並行運用と切替の手順

Go 版は Python 版と**同じデータベース・同じ写真フォルダ**を使います。
スキーマ（user_version 5）、パスワードのハッシュ形式、写真の置き場所
（`instance/photos/<個体ID>/`）は共通で、片方が書いたデータを
もう片方がそのまま読めます。このことは
`tools/interop_check.py`（両版が同じ `instance/` を交互に使う
チェック、全19項目）で確認済みです。

## 並行運用（切替前の試し運転）

Python 版を止めずに、Go 版を別のポートで試せます。

1. Go の実行ファイルを任意のフォルダに置く。
2. 環境変数 `DEVICE_DB` に、Python 版の `instance/devices.db` の
   フルパスを指定して起動する（写真も DB と同じフォルダから読みます）。

   ```
   DEVICE_DB=C:\path\to\used-device-inventory\instance\devices.db
   inventory serve --addr 127.0.0.1:5001
   ```

3. ブラウザで `http://127.0.0.1:5001/` を開き、今までの
   ユーザー名・パスワードでログインできること、一覧・詳細・写真が
   見えることを確認する。

注意: 両方を同時に長く使うことは想定していません（同時書き込みは
SQLite のロックで捌けますが、試し運転の範囲に留めてください）。
あくまで切替前の確認用です。

## 切替

1. Python 版を止める。
2. Go 版を、Python 版が使っていたアドレスで起動する。
   - `config.txt` に `addr=<Tailscale のアドレス>:5000` と書いて
     実行ファイルと同じフォルダに置くか、`--addr` で指定する。
   - `instance/` は Python 版のものをそのまま使う
     （`DEVICE_DB` で指すか、実行ファイルを Python 版の
     フォルダ構成に合わせて置く）。
3. ブラウザで開き直してログインする。**セッションは引き継がれ
   ません**（Cookie の形式が違うため）。全員、再ログインが
   必要になります。
4. 問題がなければ切替完了です。Python 版は凍結し、今後は
   Go 版だけを使います。

## 戻し方（ロールバック）

データ形式は変えていないので、いつでも戻せます。

1. Go 版を止める。
2. Python 版を今までどおり起動する。

Go 版で登録・変更した個体・経費・写真も Python 版でそのまま
読めます（相互運用チェックで確認済み）。戻した場合も、
セッションは引き継がれないので再ログインが必要です。

## Python 版との意図的な違い

- 切替時にセッションが引き継がれない（上のとおり）。
- 全フォームに CSRF 対策が入った（画面の使い勝手は変わりません）。
- `reset-password` で作り直すと、そのユーザーのログイン中
  セッションも無効になる（Python 版はログインしたまま）。
- サイズ超過（413）の戻り先判定が、URL 全体ではなくホスト名だけの
  比較になった（`tailscale serve` の HTTPS 経由でも正しく戻るため）。
- データベースの user_version は、将来版で上がっていた場合に
  下げない（Python 版は 5 に書き戻す）。

## Windows 実機での確認チェックリスト（未実施）

以下は Windows の実機でしか確認できない項目です。切替前に
一通り見てください。

- [ ] `inventory.exe` が起動すること（SmartScreen の警告が出たら
      「詳細情報」→「実行」で進める）
- [ ] `config.txt` の `addr=` で Tailscale のアドレスを指定し、
      他の端末のブラウザから開けること
- [ ] 日本語の表示が文字化けしないこと、CSV をダウンロードして
      Excel で開いても文字化けしないこと
- [ ] 実物の iPhone から写真をアップロードできること
  - [ ] 変換済み JPEG が `.HEIC` の名前のままでも通ること
  - [ ] 本物の HEIC は専用の文面（「HEIC 形式でした…」）で
        断られること
- [ ] `inventory.exe reset-password <ユーザー名>` で、
      入力したパスワードが画面に表示されない（エコーオフ）こと
- [ ] `inventory.exe list-users` が正しく一覧を出すこと
